# Connect

Aplicacion Flutter de ejemplo con un menu inferior para navegar entre tres
secciones con datos simulados:

- **Peoples:** listado de personas y estado de conexion.
- **Chats:** conversaciones recientes y mensajes sin leer.
- **Calls:** historial de llamadas entrantes, salientes y perdidas.

## Ejecucion

1. Abre el proyecto en Visual Studio Code o Android Studio.
2. Ejecuta `flutter pub get` para preparar las dependencias.
3. Inicia un emulador o conecta un dispositivo.
4. Ejecuta `flutter run`.
5. Usa el menu inferior para cambiar entre Peoples, Chats y Calls.

Las listas y acciones de llamada/chat son demostrativas; no requieren una API ni
un servicio externo.

## Pruebas

Ejecuta `flutter test` para verificar la navegacion entre las tres secciones.
